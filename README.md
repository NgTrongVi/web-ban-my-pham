# Web bán mỹ phẩm

Dự án website bán mỹ phẩm hỗ trợ hiển thị sản phẩm, tìm kiếm, đặt hàng và quản lý đơn hàng.

## Công nghệ sử dụng
- Java
- Spring Boot
- HTML, CSS, JavaScript
- MySQL

## Chức năng chính
- Hiển thị danh sách sản phẩm
- Xem chi tiết sản phẩm
- Tìm kiếm sản phẩm
- Quản lý giỏ hàng
- Quản lý đơn hàng
